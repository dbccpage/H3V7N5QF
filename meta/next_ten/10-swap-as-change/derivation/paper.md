## 2. The Five Kinds of Change and the Chosen Reading of Swap

In Ninth, a change was one of four kinds: identifying two terms, removing an assertion, adding a term, adding an assertion. In Problem 10, the seed declares:
"exchanging the relations replaces every `xry` with `xsy` and every `xsy` with `xry`, preserving each multiplicity."

### Chosen Reading (C2)
A change must modify the state. If a state has identical multiplicity distributions in both relations ($s.r = s.s$), exchanging the relations leaves the textual representation unchanged. In accordance with reading C5 of earlier derivations (where removing an unasserted pair or identifying a term with itself change nothing and are not changes), exchanging the relations on a symmetric state changes nothing and is not listed as an applicable change.

On any state where $s.r \neq s.s$, exchanging the relations yields a distinct state $\text{swap}(s) \neq s$. Exactly one swap change is available on such states.

### Unchosen Reading
Allowing an identity swap on symmetric states as an applicable change introduces a self-loop of length 1 on each symmetric state (including the empty beginning). This unchosen reading affects only self-reachability sequence counts; it does not alter the set of reachable states, nor does it reduce shortest path distances between distinct states.

### Ordering: Fewest Additions First (C3)
The seed requires attempting every change, fewest additions first.
- Identifying two terms adds 0 terms and 0 assertions.
- Removing an assertion adds 0 terms and 0 assertions.
- Exchanging the relations adds 0 terms and 0 assertions.
- Adding a term adds 1 term and 0 assertions.
- Adding an assertion adds 0 terms and 1 assertion.

Thus, exchanging the relations is a 0-addition change. It is attempted alongside identifications and removals before additions.

## 3. Invariants of One Change

### A. Involution
For every state $s$, $\text{swap}(\text{swap}(s)) = s$.
The term set $T$ is unchanged. For each pair $(x, y)$, relation $r$ receives the multiplicity previously in $s$, and relation $s$ receives the multiplicity previously in $r$. Swapping a second time restores each multiplicity.

### B. Size Preservation
The size of a state is the number of terms plus the sum of all multiplicities in both relations:
$$\text{size}(s) = |T| + \sum_{(x, y)} s.M(r, (x, y)) + \sum_{(x, y)} s.M(s, (x, y))$$
Because addition of natural numbers is commutative, exchanging the two relation sums leaves $\text{size}(s)$ unchanged:
$$\text{size}(\text{swap}(s)) = \text{size}(s) \quad (\text{D1}, \text{Lean: } \texttt{swap\_size})$$

### C. Step Size Bound
Every change of the Ninth derivation moves the size by exactly 1:
- Adding a term raises size by 1.
- Adding an assertion raises size by 1.
- Removing an assertion lowers size by 1.
- Identifying two terms lowers size by 1.
Exchanging the relations changes size by 0.

Therefore, every change $s \to t$ of Problem 10 satisfies:
$$t.\text{size} \le s.\text{size} + 1 \quad (\text{D2}, \text{Lean: } \texttt{Step10.size\_le})$$

## 4. Fewest Changes from the Empty Beginning

### A. Lower Bound
By induction on the length of a sequence of changes $h : \text{Reach10}(s, t, n)$:
$$t.\text{size} \le s.\text{size} + n \quad (\text{Lean: } \texttt{Reach10.size\_le})$$
For any sequence reaching $g$ from $\text{empty9}$:
$$\text{since } \text{size}(\text{empty9}) = 0, \quad g.\text{size} \le n \quad (\text{D3}, \text{Lean: } \texttt{fewest\_changes10\_lower})$$
Any sequence of changes reaching $g$ from the empty beginning requires at least $g.\text{size}$ changes.

### B. Upper Bound and Exact Cost
Additions alone reach every well-formed state $g$ from $\text{empty9}$ in exactly $g.\text{size}$ changes (`reach10_by_additions`). Because every addition is a valid change of Problem 10:
$$\text{fewest changes from } \text{empty9} \text{ to } g = g.\text{size} \quad (\text{D5}, \text{Lean: } \texttt{fewest\_changes10\_empty})$$
This cost is identical to Ninth.

### C. Shortest Sequences Contain No Swaps
In any sequence of changes from $\text{empty9}$ to $g$ of length $g.\text{size}$:
Every step must increase size by exactly 1.
Because swap changes size by 0, any sequence containing at least one swap must contain at least $g.\text{size}$ additions plus the swap, yielding length at least $g.\text{size} + 1 > g.\text{size}$.
Consequently:
- No shortest sequence from $\text{empty9}$ contains a swap.
- The number of shortest sequences reaching each result from $\text{empty9}$ is identical to Ninth (`count_shortest_sequences`).
- In BFS exploration from $\text{empty9}$, each result is discovered in the exact round corresponding to its size, yielding round-by-round results identical to Ninth (`exploration_summary.json`).

## 5. Transition Graph and Closed-Form Reduction Formula

While root-relative shortest paths are unaffected by swap, the general transition relation between arbitrary states is significantly altered.

### A. Single-Step Shortcuts
For any asymmetric full state $s$ ($s.r \neq s.s$ as multiplicity tables), exchanging the relations yields a single-step path to $\text{swap}(s)$:
$$\text{dist}_{10}(s, \text{swap}(s)) = 1 \quad (\text{D7})$$
Lean `reach10_swap` establishes this when the aggregate `r` and `s` counts differ; the full-state witness follows directly from the seed's swap operation.
In Ninth, swap was not a change. Any path between $s$ and $\text{swap}(s)$ in Ninth satisfies the parity relation:
$$(s.\text{size} + \text{swap}(s).\text{size} + n) \equiv 0 \pmod 2$$
Because $s.\text{size} = \text{swap}(s).\text{size}$, $2 s.\text{size} + n$ is even, which forces $n$ to be even.
If $n = 0$, then $s = \text{swap}(s)$, which contradicts asymmetry. Hence:
$$\text{dist}_9(s, \text{swap}(s)) \ge 2 \quad (\text{Lean: } \texttt{reach9\_swap\_ge\_two})$$
For example, for a state with $k$ assertions in $r$ and 0 in $s$, Ninth requires removing all $k$ assertions in $r$ and adding $k$ assertions in $s$, costing $2k$ changes. Problem 10 accomplishes this in 1 swap.

### B. At Most One Swap on Shortest Paths (D8)
Ninth changes commute with swap: for every Ninth change $u \to v$, there is a corresponding Ninth change $\text{swap}(u) \to \text{swap}(v)$ of the same kind.
If a path between two states contained two swap changes:
$$S \xrightarrow{\text{Ninth}} A \xrightarrow{\text{swap}} \text{swap}(A) \xrightarrow{L \text{ Ninth steps}} B \xrightarrow{\text{swap}} \text{swap}(B) \xrightarrow{\text{Ninth}} T$$
The intermediate segment of $L$ Ninth steps can be swapped to yield an equivalent sequence of $L$ Ninth steps from $A$ to $\text{swap}(B)$:
$$S \xrightarrow{\text{Ninth}} A \xrightarrow{L \text{ Ninth steps}} \text{swap}(B) \xrightarrow{\text{Ninth}} T$$
This sequence eliminates both swaps, reducing the total length by 2 steps.
Therefore, any shortest path between any two states contains at most one swap.

### C. Closed-Form Reduction Formula (D9)
Because any shortest path uses either 0 swaps or 1 swap:
- The shortest 0-swap path has length $\text{dist}_9(S, T)$.
- The shortest 1-swap path has length $1 + \text{dist}_9(\text{swap}(S), T)$ (taking the swap first, then following the shortest Ninth path).
Taking the minimum over both alternatives yields the exact formula:
$$\text{dist}_{10}(S, T) = \min(\text{dist}_9(S, T), 1 + \text{dist}_9(\text{swap}(S), T))$$
This formula was computed and verified across all 1024 pairs among the 32 canonical states with $n \le 2, m \le 2$ (`reduction_formula_verification.json`), showing zero discrepancies.

## 6. What Does Not Follow

1. **It does not follow that swap reduces shortest path cost from the empty beginning.**
   - *Witness where cost is not reduced*: Every well-formed state $g$. $\text{dist}_{10}(\text{empty9}, g) = g.\text{size} = \text{dist}_9(\text{empty9}, g)$.
   - *Formal refutation*: Lean theorem `what_does_not_follow_empty_cost_reduction`.

2. **It does not follow that Ninth shortest path costs are preserved between all state pairs.**
   - *Witness where cost is strictly reduced*: $S = \text{bare9}(\{0\}).\text{addAssertion}(r, 0, 0)$, $T = \text{bare9}(\{0\}).\text{addAssertion}(s, 0, 0)$. In Ninth, $\text{dist}_9(S, T) = 2$. In Problem 10, $\text{dist}_{10}(S, T) = 1$.
   - *Formal refutation*: Lean theorem `what_does_not_follow_ninth_costs_equal`.

3. **It does not follow that swap generates new reachable states.**
   - The set of reachable states is identical to Ninth: every reachable state is a well-formed two-relation state without names.
